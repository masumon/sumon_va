# UX_IMPROVEMENT_ROADMAP.md — Sumon VA

## ১. সম্পন্ন UX উন্নয়ন (আজকের সেশন)
- মসৃণ হেডার (`48×48dp` বাটন) ও নিচের নেভিগেশনে পিল চিহ্ন (`AppHeader.tsx`, `PrimaryNav.tsx`)।
- কথোপকথনভিত্তিক সহকারী চ্যাট বাবল, আইকনযুক্ত দ্রুত-বোতাম, `নিরাপদ/অটো` ব্যাজ ও `ভয়েস / ছবি` বোতাম (`f0.tsx`)।
- চ্যাট পাতায় ১-ট্যাপ `অটো/ম্যানুয়াল` ও `স্প্যাম` নিয়ন্ত্রণ (`contact.tsx`)।
- অনুমতি পাতায় ১-ট্যাপ `startService()` (`setup.tsx`, `permissions.ts`) ও হোমে অনুমতির কার্ড সবার ওপরে (`index.tsx`)।
- ফিচার নির্ভরতা স্পষ্ট করা ও কারিগরি শব্দ সরানো (`rules.tsx`, `ModuleScreen.tsx`)।
- ফোনের অডিটে পাওয়া ৫টি ভিজ্যুয়াল ফিক্স (`75737f3`)।

## ২. পরবর্তী ধাপের UX ও টেকনিক্যাল উন্নয়ন রোডম্যাপ
1. **স্বল্পমেয়াদি (পরবর্তী বিল্ডের পর):** বাস্তব ফোনে `Share → সুমন সহকারী`, `"জরুরী"` অ্যালার্ম ও স্ক্রিনশট ব্লকিং যাচাই।
2. **মধ্যমেয়াদি:** `inbox.tsx` ও `contact.tsx`-এ `FlatList` যুক্ত করা (হাজারের বেশি বার্তায় মসৃণ স্ক্রলিংয়ের জন্য) এবং হোমের ৭টি API কল একত্রিত করা।
3. **অবকাঠামো:** GitHub Actions দিয়ে দৈনিক Supabase `pg_dump` ব্যাকআপ ও বাইরের Uptime পিঙ্গার সেটআপ।
