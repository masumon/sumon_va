## ২. ব্যবহারকারীর অভিজ্ঞতায় এখনো থাকা সুযোগ (Future Polish `P2`)

1. **`routes/contact.tsx` স্টিকি রিপ্লাই বার (`P2`):** অনেক মেসেজ থাকলে উত্তর লেখার বক্সে যেতে নিচে স্ক্রল করতে হয়; ভবিষ্যতে স্থির (`sticky`) ফুটার বক্স ব্যবহারযোগ্যতা বাড়াবে।

3. **নতুন APK বিল্ড (`কমিট af792e6`, `90e5ef3`, ও আজকের `f0.tsx`):** ফোনে সর্বশেষ UI পোলিশ দেখতে একটি নতুন APK বিল্ড (`tools\build-apk.ps1`) লাগবে।
