## ২. API রাউটার ও এন্ডপয়েন্ট ইনভেন্টরি (`server/app/api/v1/routes/`)

|---|---|---|
| `health.py` | `/health`, `/health/db` (ডাটাবেজ ও সার্ভিস স্বাস্থ্য) | পাবলিক (শুধু স্ট্যাটাস, কোনো PII নয়) |
| `auth.py` | অ্যাডমিন লগইন ও টোকেন সেশন | পাসওয়ার্ড + রেট লিমিট + JWT/Session |
| `passkeys.py` | Google Passkey (WebAuthn) রেজিস্টার ও লগইন | ডিভাইস পেয়ারড + WebAuthn চ্যালেঞ্জ |
| `inbox.py` | পেয়ারিং কোড, `/device/ingest`, `/device/poll`, ডিভাইস তালিকা/বাতিল | `Bearer <device_token>` (SHA-256 হ্যাশ যাচাই) |
| `wa_assistant.py` | ইনবক্স, চ্যাট, অনুমোদন/বাতিল, `/admin/wa/f0`, `/admin/wa/analyze-media`, চ্যাট-হিস্ট্রি ইমপোর্ট, `facts` CRUD, `simulate`, `notes`, `tasks`, নিয়ম/স্ক্রিপ্ট | `owner_or_device(OWNER)` |
| `ai_hub.py` | AI প্রোভাইডার সংযোগ (Gemini, Groq, OpenRouter, Mistral, Custom HTTPS), চাবি সংরক্ষণ (`enc1:`), টেস্ট | `owner_or_device(OWNER)` |
| `integration.py` | মেইন ABO সাইট থেকে সেতু পেয়ারিং (`VA_INTEGRATION_TOKEN`) ও Telegram/Email ওয়েববুক হ্যান্ডলার | সার্ভিস টোকেন / ওয়েববুক সিক্রেট |

## ৩. ত্রুটি ও ঝুঁকি বিশ্লেষণ

1. **Render ফ্রি-টিয়ার লেটেন্সি ও কোল্ড স্টার্ট (`P2`):** `PollService` ২০ সেকেন্ড পরপর লং-পোল করায় সার্ভার সাধারণত সজাগ থাকে, তবে ফোন বন্ধ বা নেটওয়ার্ক বিচ্ছিন্ন থাকলে প্রথম কল (`ReadTimeout`) `৭৫ সেকেন্ড` পর্যন্ত সময় নিতে পারে (`Core.kt:99`-এ যা ঠিকভাবে সামলানো আছে)। স্বাভাবিক অবস্থায় ঢাকা → সিঙ্গাপুর লেটেন্সি ~`১.৭–১.৯ সেকেন্ড`।
2. **`Pydantic` ও `datetime.utcnow()` ওয়ার্নিং (`P3`):** `pytest`-এ ৩২টি ডিপ্রেক্যাশন ওয়ার্নিং (`app/core/rate_limit.py:27`, `starlette` ও `pydantic` `class Config`) দেখা গেছে—ভবিষ্যতে Python 3.13+/Pydantic v3-তে যাওয়ার আগে পরিষ্কার করা ভালো, তবে এখন কোনো ফাংশনাল ত্রুটি নেই।
3. **ইনবাউন্ড ইনজেস্ট ভ্যালিডেশন ও ৪২২ হ্যান্ডলিং (`PASS`):** কোনো একটি মেসেজ ব্যাকএন্ড রিজেক্ট করলে (`400`/`413`/`422`) পুরো ব্যাচ না ফেলে `Core.kt:162-177` একটি করে আলাদা পাঠিয়ে শুধু ত্রুটিপূর্ণ মেসেজটি বাদ দেয়; সার্ভার এরর (`5xx`) হলে কিউ থেকে মুছে না।
4. **মাস্টার অফ অবস্থায় `f0` / Telegram অনুমোদন (`PASS`):** মাস্টার সুইচ বন্ধ থাকলেও সুমন ভাই নিজে `/f0` বা `@SumonVA_bot`-এ খসড়া/অনুসন্ধান চালাতে পারেন।
